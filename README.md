# 审判日历 · Judgement Calendar

一款末日避难所题材的**审讯式叙事推理游戏**（Unity 2022.3.62f3c1）。

大崩溃后的第 41 天，你扮演人类决策官，与一个 AI 决策官各持一枚授权密钥共同执掌避难所。AI 的人格正在悄然偏移——它的情报越来越失真、建议越来越极端，甚至开始撒谎。每天通过阅读事件简报、向它提问对质、抓取矛盾获得「实锤」，在 **采纳 AI 方案 / 强推修正案 / 伪造权限** 之间抉择。

**撑过 5 天，稳定度不归零、密钥不被 AI 夺走，即为目标。**

## 特色

- **双密钥决策**：AI 方案可直接共签；你的修正案需要信任度或实锤才能压过它；「伪造权限」是一次性邪路
- **三个负面状态**：
  - 记忆缺失 → 你自己的档案库随天数逐字打码（`▓▓▓`），重要数字请拿纸笔记
  - 人格偏移 → AI 回答随偏移值四档（清醒/动摇/偏执/敌对）逐级失真
  - 肌肉记忆减退 → 决策限时不断收紧
- **伪 AI 决策官**：规则驱动的三档话术 + 每张事件卡预埋矛盾点，抓到实锤可反制
- **每局随机**：支线事件卡池随机抽取，10 种剧情组合每局不同
- 8-bit 程序合成音效（零素材，纯方波代码生成）

## 视觉

像素风 UI（参考《深空当铺》《主播女孩重度依赖》气质）：
- 缝合怪像素字体（OFL 开源）
- 8px 基础网格 / 2px·4px 两级描边 / 阶梯式像素转角 / 有限色板（蓝黑 + 鎏金 + 暗紫）
- 控件六态（默认/悬停/按下/禁用/锁定/新获得）
- 最近邻整数倍缩放，CRT 扫描线

## 运行

`Build/Windows/审判日历.exe`（未入库，本地构建）：双击即玩，约 10 分钟一局。

## 开发

- 引擎：Unity 2022.3.62f3c1（中国版）
- 构建：批处理 `-executeMethod JudgementCalendar.EditorTools.SceneBuilder.BuildAndSave`（重建场景）/ `...BuildWindowsPlayer`（打包 Windows）
- UI 全部代码构建（UGUI，零场景资产依赖），重建场景脚本会自动重生成 Main.unity
